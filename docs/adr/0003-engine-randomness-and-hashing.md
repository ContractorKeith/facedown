# Engine randomness and hashing are hand-rolled and canonical

The engine cannot use `crypto`, `TextEncoder` or `Math.random` (it must run unchanged in the browser replay viewer and stay deterministic), so it carries its own sha256 and PRNG. The PRNG is sfc32: four 32-bit words of state, seeded by folding all eight words of the seed's sha256 digest into those four, producing unsigned 32-bit outputs. Bounded draws use rejection sampling, because a plain modulo is biased whenever the bound does not divide 2^32 and a biased shuffle would be a rigged deal. sha256 encodes UTF-8 itself, replacing unpaired UTF-16 surrogates the same way `TextEncoder` does, so a hash computed in the engine matches one computed anywhere else. Anything hashed (the move-log chain in ADR 0002, final-state hashes in goldens) goes through canonical JSON: object keys sorted recursively, array order and scalar values significant, and engine state never contains `undefined`.
